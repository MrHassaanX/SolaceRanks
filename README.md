# SolaceRanks v1

An advancement-based rank progression plugin originally created for SolaceMC.

SolaceRanks v1 tracks completed Minecraft advancements, determines a player's rank from the original SolaceMC thresholds, and synchronizes that rank with LuckPerms.

## Legacy Branch

This branch contains the legacy SolaceRanks 1.x implementation.

The exact original v1.0.0 release is permanently preserved by the `v1.0.0` Git tag. This branch may contain documentation or maintenance updates for the 1.x line, while future SolaceRanks v2 development is separate.

## Features

- Advancement-based rank progression
- Completed advancement counting
- Recipe advancements ignored
- LuckPerms API integration
- Rank synchronization through LuckPerms groups
- Rank updates when players join
- Rank updates when advancements are completed
- UUID-based player data
- Bedrock/Floodgate support
- `br_` username fallback for Bedrock detection when Floodgate is unavailable
- Configurable promotion broadcasts
- Configurable promotion titles
- Configurable promotion sounds
- Persistent player database
- Rank leaderboard
- Admin synchronization, recalculation, and info commands
- Permission-based command access

## Compatibility

SolaceRanks v1.0.0 was developed against:

- Paper `1.21.8`
- Java `21`

It was also successfully used on:

- Minecraft/Paper `26.2`

Minecraft/Paper `26.3` was not formally tested for the original v1 release.

Do not treat untested versions as officially supported. SolaceRanks may work on additional versions where the Bukkit/Paper APIs it uses remain compatible, but only tested versions are listed as confirmed.

## Requirements

- Paper
- LuckPerms
- Java `21` for the original build
- Floodgate optional

LuckPerms is required. Floodgate is optional and is detected automatically when installed.

## Installation

Download the preserved release:

[https://github.com/MrHassaanX/SolaceRanks/releases/tag/v1.0.0](https://github.com/MrHassaanX/SolaceRanks/releases/tag/v1.0.0)

Use:

```text
SolaceRanks-1.0.0.jar
```

Basic installation:

1. Install LuckPerms.
2. Place `SolaceRanks-1.0.0.jar` in the server's `plugins/` directory.
3. Start or restart the server.
4. Configure `config.yml` and `messages.yml` as needed.
5. Restart the server or use the reload command.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/rank` | Shows your current rank, advancement count, and next rank. | `solaceranks.rank` |
| `/rank top` | Shows the top 10 stored players by completed advancements. | None beyond command access |
| `/rank help` | Shows the command help menu. Admin-only entries are shown only to admins. | None for the command itself |
| `/rank reload` | Reloads plugin configuration and updates online players quietly. | `solaceranks.admin` |
| `/rank sync <player>` | Recalculates and synchronizes a stored or online player's rank. | `solaceranks.admin` |
| `/rank recalculate` | Recalculates all stored player ranks against the current thresholds. | `solaceranks.admin` |
| `/rank info <player>` | Shows detailed stored rank information for a player. | `solaceranks.admin` |
| `/playerrank <player>` | Shows another stored player's rank, advancement count, next rank, and remaining advancements. | `solaceranks.playerrank` |

## Permissions

| Permission | Default | Description |
| --- | --- | --- |
| `solaceranks.rank` | `true` | Allows players to use `/rank`. |
| `solaceranks.playerrank` | `true` | Allows players to use `/playerrank <player>`. |
| `solaceranks.admin` | `op` | Allows administrative commands. |

The following commands require `solaceranks.admin`:

- `/rank reload`
- `/rank sync <player>`
- `/rank recalculate`
- `/rank info <player>`

## Configuration

SolaceRanks v1 uses:

- `config.yml` - rank thresholds, promotion broadcast setting, promotion title settings, promotion sound settings, and `/playerrank` formatting.
- `messages.yml` - configurable plugin messages.
- `players.yml` - runtime player database generated automatically by the plugin.

The player database stores UUID, username, Java/Bedrock status, current rank, previous rank, advancement count, first join, and last seen.
